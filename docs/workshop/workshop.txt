description=[h1]What it does[/h1]
description=Project Zomboid loads and bakes the map in chunks; on stock, the loading, baking and lighting work of a busy screen lands in the same frame and shows as stutter while driving or turning. These overrides move that work off the game thread, spread it over frames, and cache what stock recomputes every frame (puddles, rain, cutaways, lights, sound zones). At 5120x2160 on an RTX 4090: driving p99 frame time 19 -> 8 ms, uncapped ~270 -> ~500 fps, thunderstorms 83 -> 188 fps.

description=[h1]How it works[/h1]
description=The launcher (ProjectZomboid64.json) searches the game folder before projectzomboid.jar, so a loose .class file with the same name as one in the jar replaces it. The item holds those files (485 files: 87 shadowed game classes, the pzopt package, Lua, preview clips, a manifest) under [b]pzopt-classes[/b]; projectzomboid.jar is never modified. A guard checks the game revision and the sha256 of every shadowed stock class at start-up; on any difference the game runs as stock (one log line).
description=
description=[h1]Install on Windows[/h1]
description=1. Subscribe, let Steam download the item, close the game.
description=2. Open PowerShell (Start menu, type powershell) and run (adjust the drive if your Steam library is elsewhere):
description=[code]powershell -ExecutionPolicy Bypass -File "C:\Program Files (x86)\Steam\steamapps\workshop\content\108600\3805285544\mods\PZ_Optimization\42\install.ps1"[/code]
description=The script finds the game through Steam's library list, checks the revision, refuses to overwrite existing files and records what it copied in pzopt-installed.txt.
description=3. Launch from Steam. The first boot is a few seconds slower (caches under Zomboid\pzopt\); console.txt shows one "[pzopt] loaded override ... active" line per class.
description=
description=Uninstall: the same command with -Uninstall. -Status lists what is installed and whether any file changed.
description=

description=[h1]Performance overlay (F9 / L3 + R3)[/h1]
description=Off by default: tick "Sample frame times and utilization" in Options > Profiler (no restart), then F9 or a pad's L3 + R3 toggles it. Frame time, its tail (p99 / p99.9 / max, 1 %-low, jitter, spikes), GPU busy, game- and render-thread load, a verdict line, the game-thread tree and flame graph below, the frame graph; every element is a dropdown there. Same on every platform, no MangoHud / RivaTuner.
description=[img]https://raw.githubusercontent.com/xD3I/PZ_Optimization/master/docs/workshop/images/13-profiler.jpg[/img]
description=
description=[h1]Settings[/h1]
description=Options > Optimizations (saved to Zomboid/pzopt/options.ini, applied on the next launch) has every key with a tick box, a stock-vs-optimized clip and effect bars for the setting under the mouse, plus "Disable all (stock game)" / "Enable all". Options > Display gains an "Uncapped" framerate entry and a separate menu framerate.
description=
description=[h1]Updates[/h1]
description=After the first install the main-menu item updates the files (one GitHub request per boot; off in Options > Optimizations > Updates). The files are built for one game revision: after a game update the game runs as stock until the build for the new revision is out.
